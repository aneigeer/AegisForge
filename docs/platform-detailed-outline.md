# 企业级数据库漏洞检测与自进化修复平台 — 详细架构与功能大纲

## 一、平台总体定位与核心闭环

### 1.1 平台定位
面向企业级异构数据库（PostgreSQL / MySQL / Redis / TiDB / Oracle）的零信任漏洞探测、出站双向可逆脱敏、容器化沙箱 PoC 与 Dry-Run 验证、画布内 HITL 人工审批及受控自进化修复平台。

### 1.2 端到端业务闭环
1. **异构资产纳管与动态凭据**：KMS / HashiCorp Vault 动态签发短期只读凭据（零明文落盘）
2. **多维低侵入漏洞探测**：CIS / 等保 2.0 基线、CVE 版本匹配、弱口令与过度授权、慢查询与存储过程风险
3. **业务上下文风险定级**：结合资产业务等级、公网/内网暴露面与 PII 敏感数据分布，过滤低价值噪音告警，输出 P0~P3 优先级
4. **模型网关与双向可逆脱敏**：L1 本地私有模型 + L2 强推理模型分级路由；外发 Prompt 前自动替换真实表名、IP 与敏感值，返回后本地自动还原
5. **分层修复与强制回滚生成**：生成临时缓解、标准修复 SQL 与升级路径，强制配套生成 Rollback 回滚脚本与锁表/重启影响评估
6. **容器化沙箱验证 (Harness)**：拉起同版本空表隔离沙箱，执行「阶段 1：漏洞 PoC 复现消误报 -> 阶段 2：修复脚本 Dry-Run -> 阶段 3：安全复测与业务 SQL 兼容性回放」
7. **HITL 双人人工审批断点**：高危变更在工作流画布内挂起，支持长按边框蓄力防误触审批，并同步外部工单（飞书 / 钉钉 / Jira）
8. **生产原子执行与回滚保护**：通过临时提权通道执行变更并开启健康度观测，异常激增时自动触发 Rollback 脚本
9. **可开关自主进化引擎**：从历史误报与人工修改中蒸馏检测规则与领域记忆，支持静态/进化模式一键切换、Shadow Mode 影子测试与 Git 风格版本秒级回滚
10. **全链路 WORM 审计与生态集成**：SHA-256 不可篡改哈希链记录全流程日志，支持导出 PDF / SARIF v2.1.0 报告并对接 CMDB、SIEM 与 CI/CD

## 二、四大架构层与十大核心模块详细大纲

### 2.1 【交互编排层】

#### 模块 01：工作流可视化编排引擎
- **核心定位**：提供拖拽式 DAG 节点编排、条件分流、运行时节点状态高亮、流式日志查看，以及画布内的人工审批断点（HITL）。
- **功能细项**：
  - **8 节点 S 型 DAG 拓扑编排**：覆盖「资产探测 -> 多维检测与定级 -> 隐私网关 -> AI 修复生成 -> 沙箱 Harness -> HITL 审批断点 -> 安全执行与回滚保护 -> 自主进化引擎」，支持节点点击检视与鼠标拖拽布局。
  - **条件自动分流**：沙箱 PoC 未复现的告警自动分流至「误报抑制分支」；P0/P1 高危变更自动挂起进入「HITL 人工审批断点」。
  - **运行时状态可视化**：执行中节点青色呼吸光晕、待审批节点琥珀色呼吸光晕、完成节点翠绿色高亮、虚线粒子流动连线及实时日志流（Live Stream）。

#### 模块 02：资产与凭据管理模块
- **核心定位**：纳管异构数据库资产并打业务重要性标签；对接 KMS / Vault 实现密码加密与动态凭据，避免明文落盘。
- **功能细项**：
  - **异构数据库统一纳管**：支持 MySQL、PostgreSQL、Redis、TiDB、Oracle 等多源实例，支持一键同步 CMDB 资产。
  - **三维业务上下文标签**：为每个资产绑定「业务等级（核心 P0 / 重要 P1）」、「网络暴露面（公网跳板映射 / 严格内网隔离 / 内网 VPC）」与「敏感数据分布（含 PII / 财务核心）」。
  - **零信任动态凭据托管**：对接 HashiCorp Vault / KMS / 本地 Fernet 主密钥箱，按需签发短期动态只读租约（TTL=15m），所有连接串与密码零明文落盘。

### 2.2 【检测验证层】

#### 模块 03：多维漏洞检测引擎
- **核心定位**：低侵入/限流探测，覆盖配置合规基线（CIS / 等保）、CVE 版本匹配、弱口令及慢查询/存储过程深度风险分析。
- **功能细项**：
  - **低侵入限流探查**：强制限制探查并发与速率（QPS <= 20，实例 CPU 峰值增量 < 1.8%），保障生产业务零抖动。
  - **CIS / 等保 2.0 配置基线核查**：覆盖高危配置缺陷（如 MySQL `secure_file_priv=""` 允许任意路径读写、PostgreSQL `idle_in_transaction_session_timeout=0` 锁放大、连接审计缺失、Redis 未禁用高危命令）。
  - **CVE 版本与提权链匹配**：精准识别数据库引擎版本漏洞（如 `CVE-2024-7348`）及组合提权路径。
  - **权限、慢查询与存储过程深度分析**：检测业务账号过度授权（`GRANT ALL PRIVILEGES ON *.*`）、弱口令策略，以及 `SECURITY DEFINER` 存储过程未锁定 `search_path` 导致的动态 SQL 注入风险。

#### 模块 04：上下文风险定级模块
- **核心定位**：结合资产等级、网络暴露面（公网/内网）和敏感数据分布，过滤低价值告警，输出真实业务风险优先级。
- **功能细项**：
  - **多因子上下文风险评分模型**：综合 `基础 CVSS 分值 × 资产业务等级权重 × 网络暴露面权重 × PII 敏感数据权重`，输出 `0.0 ~ 10.0` 真实业务风险分（如公网跳板 + 核心订单库组合提权定为 `9.1 高危`）。
  - **低价值噪音自动过滤**：对严格内网隔离且无敏感数据的非核心实例轻微配置提示自动降级过滤，避免告警疲劳。
  - **四级处置优先级输出**：标准化输出 `P0（紧急阻断）`、`P1（高危限期）`、`P2（中危收敛）`、`P3（低危观察）`。

#### 模块 05：修复方案生成模块
- **核心定位**：生成分层修复策略（临时缓解 / 标准修复 SQL / 升级路径），并强制配套生成 Rollback 回滚脚本与锁表/重启影响评估。
- **功能细项**：
  - **三层分级修复策略**：
    1. **临时缓解（Tier-1）**：WAF 拦截规则、临时回收高危 Schema 公有权限或终止长事务会话；
    2. **标准修复 SQL（Tier-2）**：按最小权限原则生成的精确修复脚本（如 `REVOKE ALL` + 细粒度 `GRANT` + `SET PERSIST local_infile = OFF`）；
    3. **版本升级路径（Tier-3）**：配套内核补丁滚动升级方案与维护窗口配置项下发建议。
  - **强制配套 Rollback 回滚脚本**：每一份修复方案必须强制生成经过校验的完整逆向回滚脚本（如恢复权限快照 `#SNAP-094`），缺少回滚脚本的方案严禁进入下游环节。
  - **变更影响量化评估**：明确标注「锁表风险（无锁表 / 轻量元数据锁 / 排他锁）」、「是否需重启实例（在线生效 / 需重启）」及「预计执行耗时（如 `< 150ms`）」。

#### 模块 06：容器化沙箱验证模块 (Harness)
- **核心定位**：自动拉起同版本脱敏/空表沙箱，先跑 PoC 消除误报，再 Dry-Run 验证修复脚本是否生效及是否破坏业务兼容性。
- **功能细项**：
  - **同版本隔离容器沙箱拉起**：按目标资产引擎版本（如 `mysql:8.0.32-sandbox` / `pg:16.2-sandbox`）自动拉起空表 Schema 沙箱，零生产敏感数据接触。
  - **三阶段自动化验证流水线**：
    1. **阶段 1（漏洞真实性 PoC 验证）**：在沙箱内重放无害化漏洞 PoC（如 `SELECT INTO OUTFILE` 与越权读表），确认漏洞真实存在，彻底消除静态规则误报；
    2. **阶段 2（修复脚本 Dry-Run）**：在沙箱内预执行 AI 生成的标准修复 SQL 与回滚脚本，实测执行耗时与语法正确性；
    3. **阶段 3（安全复测与业务兼容性回放）**：复测漏洞 PoC 确认已完全拦截，并自动回放 240 条脱敏高频业务 SQL，确保 `100% 业务兼容无报错`。

### 2.3 【AI 与进化层】

#### 模块 07：统一模型网关与脱敏模块
- **核心定位**：统一接入外部 API 与本地模型（vLLM / Ollama），按任务难度分级路由；外发 Prompt 前自动替换真实表名、IP 与敏感值，返回后还原。
- **功能细项**：
  - **多模型分级路由架构 (BYOM / BYOK)**：
    - **路由层 L1（本地私有化）**：接入内网 `vLLM / Ollama (Qwen2.5-14B)`，承担高吞吐慢查询解析、AST 语法树提取与基线枚举，数据 100% 不出内网；
    - **路由层 L2（外部强推理 API）**：脱敏接入 `Claude 3.7 Sonnet / DeepSeek / GPT-4o`，承担复杂跨表提权链推理、精准修复 SQL 与 Rollback 脚本生成及沙箱报错自愈；
    - **路由层 L2-B（私有灾备集群）**：接入内网 `DeepSeek-R1 私有集群`，在外部 API 超时或机密级资产场景下自动故障转移。
  - **出站双向可逆隐私脱敏网关 (Zero-Leak Guard)**：
    - **四重脱敏策略开关**：① 真实表名与字段名脱敏（`prod_pay_users` -> `tbl_masked_01`）；② IP 地址与主机名脱敏（`10.24.8.19` -> `10.x.x.19`）；③ 账号密码与 Token 强拦截（`[REDACTED_CRED]`）；④ 样本 PII 敏感数据替换（手机号/身份证/银行卡 -> `[MASKED_PHONE]`）；
    - **本地内存态自动还原**：外部大模型返回基于掩码表名的修复 SQL 后，隐私网关在本地内存态根据加密映射表自动还原为真实生产表名与账号标识。

#### 模块 08：可开关自主进化引擎
- **核心定位**：提供静态/进化模式一键开关；从历史误报与人工修改中蒸馏新规则、沉淀企业专属领域记忆，支持影子测试（Shadow Mode）与进化版本回滚。
- **功能细项**：
  - **全局静态 / 进化模式一键开关**：
    - **开启（影子测试受控模式）**：自动从历史误报、DBA 修改记录与沙箱验证结果中蒸馏检测规则与领域记忆；
    - **关闭（纯静态确定性模式）**：仅使用冻结的静态合规基线与固定 Prompt 运行，DAG 画布中的「自主进化节点」自动虚线旁路（`已跳过`），满足严格合规冻结窗口要求。
  - **影子测试（Shadow Mode）与安全边界**：所有新蒸馏规则必须先进入影子测试队列旁路比对（如通过率 `99.2%`），且严格遵循安全边界——**仅进化检测规则与领域记忆，绝不越权修改生产执行权限**。
  - **Git 风格进化快照与秒级回滚**：对每一版领域记忆库与规则集（`v1.8` / `v1.7` / `v1.6`）进行快照管理，展示影子测试得分与新增规则数，当发现指标退化时支持一键秒级回滚至任意历史稳定版本。

### 2.4 【企业治理层】

#### 模块 09：权限与审批流模块
- **核心定位**：实现多租户隔离与细粒度 RBAC（安全 / DBA / 审计分离）；高危修复强制走人工审批或对接外部工单（Jira / 飞书 / 钉钉）。
- **功能细项**：
  - **多租户隔离与三权分立 RBAC**：按业务域（如「生产金融域」）严格隔离，内置三类分离角色：
    - **高级 DBA (`DBA`)**：负责审查修复 SQL / 回滚脚本、批准 HITL 断点并执行变更；
    - **安全工程师 (`SEC`)**：负责发起漏洞探测、风险定级与进化规则蒸馏；
    - **合规审计员 (`AUD`)**：拥有只读审计权限，负责核验 WORM 哈希链与导出合规报告。
  - **画布内 HITL 长按蓄力审批断点**：P0/P1 高危修复强制在节点 6 挂起，提供「修复 SQL / Rollback 回滚 / 沙箱报告 / 脱敏对比」四维审查视图，并采用**长按沿边框填充进度（未满松开弹性回弹、填满微震动锁定）**机制防止误触放行。
  - **外部工单协同集成**：自动生成结构化变更审批载荷并同步至飞书、钉钉或 Jira 工单系统（如变更单 `#CHG-2026-8841`）。

#### 模块 10：全链路审计与生态集成模块
- **核心定位**：不可篡改记录扫描、模型调用（含脱敏记录）、审批与执行日志；支持导出 PDF / SARIF 报告，对接 CMDB、SIEM 与 CI/CD。
- **功能细项**：
  - **WORM 不可篡改 SHA-256 哈希链审计**：全量记录动态凭据签发、低侵入漏洞扫描、出站脱敏调用、沙箱验证、DBA 人工审批、生产脚本执行及进化版本回滚，每条日志包含前后衔接的 SHA-256 防篡改校验哈希。
  - **标准化报告导出（PDF / SARIF v2.1.0）**：支持一键导出符合等保 2.0 规范的审计报告与标准 SARIF v2.1.0 漏洞分析文件，可直接接入 GitHub / GitLab CI/CD 安全门禁。
  - **企业安全生态集成**：内置 CMDB 资产增量同步接口与 SIEM 安全信息事件管理实时日志转发能力。

## 三、原生桌面端五大视图与特色交互汇总

1. **视图 1 — 工作流编排**：8 节点可拖拽 S 型 DAG 画布 + 右侧 4-Tab 节点检视器（`修复 SQL` / `Rollback 回滚` / `沙箱报告` / `脱敏对比`）+ 底部长按边框蓄力批准/驳回栏。
2. **视图 2 — 资产与凭据**：4 项零信任统计卡片 + 5 台异构数据库实例清单（业务等级、网络暴露面、Vault 动态凭据、上下文风险评分）+ CMDB 同步。
3. **视图 3 — 模型网关与脱敏**：L1 本地 / L2 云端 / L2-B 灾备三层路由状态卡 + 4 项出站隐私脱敏规则实时开关 + 出站 Prompt 实时脱敏 JSON 预览 + BYOK 密钥加密配置弹窗。
4. **视图 4 — 自主进化中心**：自主进化/静态确定性模式联动横幅 + 误报率下降/首通率/领域记忆库三大指标 + Git 风格版本历史与一键回滚。
5. **视图 5 — 审计日志**：WORM 不可篡改 SHA-256 哈希链审计日志表 + 一键导出 PDF / SARIF 审计报告 + 左下角三权分立 RBAC 角色切换器。
6. **特色交互**：
   - **长按边框蓄力审批**：按住时沿按钮四条边框顺时针填充进度，未满松开弹性阻尼回弹清空，填满后变为已批准/已驳回状态并触发轻微震动反馈。
   - **慢速圆心扩散主题切换**：点击右上角太阳/月亮按钮，图标 360° 旋转变形，同时以按钮为圆心按 1.4 秒 SmoothStep 曲线向外平滑扩散切换深浅配色。
